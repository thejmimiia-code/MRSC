Prix des carburants en France, flux instantané — fiche du jeu de données lue le 14 novembre 2026 par son API publique.

« Les données mises à disposition sont les informations extraites du système d’information “Prix des carburants”. »

« Chaque ligne contient tous les carburants, les prix et les services proposés pour un point de vente. »

« Les données ouvertes comprennent : les informations générales sur un point de vente : adresse, coordonnées géographiques, horaires d’ouverture et services proposés ; les carburants proposés par le point de vente ; les prix des carburants figurant dans le système d’information ; les dates et heures de mises à jour des prix. »

« Le flux de données instantané est mis à jour toutes les 10 minutes. »
