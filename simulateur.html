À quoi ça sert

Mesurer les effets d’une décision avant de la prendre

Les débats publics opposent souvent des intentions. Le simulateur, lui, applique des décisions à un modèle économique et institutionnel : chaque curseur déplacé se propage du budget communal jusqu’à l’échelon géopolitique, avec les recettes, les dépenses et les indicateurs de tension qui en découlent.

Il ne prédit rien et ne remplace personne : c’est un instrument de discussion, conçu pour rendre visibles les arbitrages, les délais et les effets de bord d’un programme — avant le vote, pas après.

Vous souhaitez revoir les notions de données, de pourcentages ou d’IA avant de l’explorer ? Parcourir les ressources par matière et par niveau.

L’outil

Accéder au simulateur interactif

La version interactive est publiée sur Vercel. Lorsqu’elle peut être intégrée, la console de veille affiche en permanence le verdict de chaque échelon : ce qui reste tolérable, ce qui passe en vigilance, ce qui devient risqué ou hors-sol. Les valeurs de départ sont datées et sourcées ; le bouton Rafraîchir les données interroge les API publiques depuis votre navigateur.

Le simulateur interactif est publié sur Vercel ; une copie embarquée est conservée comme repli. Ouvrir le simulateur interactif · dépôt du simulateur · version embarquée : révision inconnue. La copie embarquée peut différer de la version hébergée ; sa révision et sa date de copie sont indiquées ici.

L’aperçu intégré n’a pas pu être chargé. Le simulateur interactif est publié sur Vercel. Ouvrez-le directement si l’intégration dans cette page n’est pas disponible : d-mocratie-et-politique-du-peuple-p.vercel.app. La copie embarquée ne calcule que lorsqu’un hébergeur compatible exécute également les fonctions Python du site ; vous pouvez aussi lancer l’outil localement avec python3 outils/serveur-local.py après avoir cloné le dépôt.

L’affichage intégré est réduit : sur téléphone ou pour travailler sur plusieurs réglages à la fois, ouvrez le simulateur interactif en plein écran. Chiffres et verdicts proviennent du moteur et de sources publiques. Le simulateur ne demande pas de compte ou d’identité ; les requêtes à Vercel peuvent toutefois inclure des données techniques comme l’adresse IP. Voir la notice de confidentialité.

Ce que montre le simulateur

Ce qu’il fait — et ce qu’il ne fait pas

Ce qu’il fait

  • propager une décision dans les cinq échelons, avec les recettes et dépenses associées ;
  • afficher les marges de manœuvre restantes et les seuils franchis, échelon par échelon ;
  • croiser chaque levier avec les 20 domaines d’impact, mesure par mesure ;
  • expliquer chaque réglage (plage, défaut, effets déclarés, chaîne d’interaction) ;
  • exporter la simulation complète en JSON ou CSV pour la discuter ou l’auditer.

Ce qu’il ne fait pas

  • il ne prédit ni élection, ni croissance : c’est un modèle, donc une simplification assumée ;
  • il ne remplace pas l’expertise des services publics ni le débat démocratique ;
  • les valeurs de référence sont datées et versionnées, pas continuelles : la date est affichée ;
  • hors connexion aux API publiques, il retombe sur un référentiel daté, explicitement signalé ;
  • il ne demande ni compte ni identité ; les réglages envoyés à l’API et les données techniques de l’hébergement sont décrits dans la notice de confidentialité.
